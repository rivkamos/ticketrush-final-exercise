# 🎟️ TicketRush – תרגיל מסכם בגיט

## הסיפור

הופעת האיחוד של השנה. **20,000 כרטיסים. שעה אחת.**

את המפתחת הראשית של **TicketRush**, האתר שמוכר את הכרטיסים להופעה הכי מצופה של השנה. בעוד **שעה בדיוק** נפתחת המכירה לקהל. אלפי אנשים כבר בתור, והמפיקים לא ידחו את הפתיחה בדקה.

האתר כמעט מוכן, אבל לא לגמרי: יש פיצ'ר אחרון לסיים, והצוות שלך ישלח אלייך הודעות באמצע העבודה. חלקן קריטיות, חלקן מבלבלות, ואחת מהן עלולה להרוס את המכירה אם לא תטפלי בה נכון.

**מה נבדק:** כל מה שלמדנו בקורס. ענפים, Worktrees, מיזוג והתנגשויות, שחזור טעויות, בחירה נכונה בין הכלים (revert, cherry-pick, bisect ועוד), ועבודה מסודרת תחת לחץ.

---

## מה צריך

- Git מותקן, ו-VS Code (או כל עורך אחר)
- **Node.js** (גרסה 18 ומעלה). בדיקה: `node -v`
- חשבון GitHub עם הרשאת כתיבה למאגר הזה

## הכנה (5 דקות, השעון עדיין לא רץ)

1. שכפלי את המאגר למחשב שלך:
   ```bash
   git clone <כתובת המאגר>
   cd <שם התיקייה>
   ```
2. הפעילי את מוקד ההתראות:
   ```bash
   node start.js
   ```
   הסקריפט ישאל את השם שלך באנגלית (למשל `rachel-cohen`), יפעיל את שעון ה-60 דקות ויפתח **לשונית בדפדפן** שבה יופיעו ההתראות.
3. בלשונית שנפתחה, לחצי **"הפעלת התראות"** כדי שההתראות יקפצו גם מעל חלונות אחרים.
4. **אל תסגרי** את חלון הטרמינל של `start.js`, ואל תסגרי את לשונית הדפדפן. תעבדי בטרמינל אחר (או בטרמינל של VS Code).

> אם בטעות סגרת: הריצי שוב `node start.js`. השעון ממשיך מאיפה שהיה ולא מתאפס.

> **שימי לב:** ההתראות נשמרות גם כקבצים בתיקיית `ALERTS/`, אפשר לקרוא אותן שוב בכל רגע.

## הכללים

1. **כל משימה מקבלת ענף משלה ו-Worktree משלו** (תיקייה נפרדת). התיקייה הראשית נשארת על `main` ונקייה.
2. **אסור לשכתב או למחוק היסטוריה משותפת** (`main` כבר בשימוש של כל הצוות).
3. הודעות קומיט ברורות. `fix` או `asdf` מורידים נקודות.
4. לא כל התראה דחופה באמת. קראי בעיון לפני שאת פועלת.
5. הכול נעשה על המחשב שלך. אינטרנט נדרש רק לשכפול בהתחלה ולהגשה בסוף.
6. **אסור** לדחוף ל-`main` שבמאגר. ההגשה נעשית בעזרת `finish.js`.

## הגשה

כשסיימת (או כשנגמר הזמן), מהתיקייה הראשית:

```bash
node finish.js
```

הוא בודק את העבודה, מראה לך ציון ופירוט, ושואל אם לדחוף את הענפים שלך ל-GitHub (תחת השם שלך, בלי לגעת ב-`main`).

## שקיפות: מה נרשם

כדי שהתרגיל יעבוד, `start.js` רושם **מקומית** (בתוך תיקיית `.git`) מתי הגיעו ההתראות, אילו Worktrees נפתחו ובאילו רמזים השתמשת. `finish.js` שולח את זה יחד עם תוצאות הבדיקה למרצה. שום דבר אחר לא נאסף.

## אם משהו תקוע

- `node start.js` לא עובד: בדקי ש-`node -v` מציג גרסה 18 ומעלה.
- ההתראות לא מקפיצות הודעה: זה בסדר, הן מופיעות בלשונית ובתיקיית `ALERTS/`.
- שאלה על התרגיל עצמו: הרימי יד.
